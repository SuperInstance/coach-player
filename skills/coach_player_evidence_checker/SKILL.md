# Evidence Checker

Use before publishing roster facts, freezing a template or telling the owner a character is ready.

## Method

- Take the claim and find the exact source it rests on, either a channel record, a transcript segment or a session log.

- Recompute or re read the source values yourself instead of trusting the summary that carried the claim.

- Flag any number that arrived before its source returned, and replace it with the source value or with an unverified label.

- Check a shading by sampling one segment it cites and confirming the tagged move and timing are really there.

- Report the deficit first, what failed and what is still unproven, before listing what passed.

- Block the professional gate while any profile band in use rests on unchecked claims.
