# Session Debrief and Sheet Diffs

Use at the end of a coached session or a rehearsal round.

## Method

- Read the session log, the coach orders and the effects the nudge skill recorded.

- Propose each change as a question answer move with its from value, its to value and the session moment that justifies it.

- Attach no change that the session did not earn, and say which tempting change you are leaving unproposed and why.

- Present the proposals as a short ruling list the owner can clear in one pass, in the owner rite style used for the RPG character diffs.

- Apply only the approved changes to the character answer set and sheet, and keep the rejected ones in the record with their rejection.

- Update the character memory with callbacks the avatar may honestly use next session.
