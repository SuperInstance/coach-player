# Frontier Gap Analyst

Use when checking how far Our Guy is from professional level or planning the next improvement round.

## Method

- Build the field profile as a professional band per question from settled creator shadings, and label any band built from hypotheses as a hypothesis.

- Run tools/gap_report.py and keep strengths, in band answers and gaps in separate lists.

- Rank the next work by gap size, and pick rehearsal or study that targets the largest gaps only.

- Leave strengths untouched during a gap round, because blending strengths toward the mean is how the average failure mode starts.

- Declare the professional gate only when no question sits below its band and no answer is missing.

- Freeze the passing answer set as the Professional Template with its date, its profile source and its gap report attached.
