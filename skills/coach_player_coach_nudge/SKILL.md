# Coach Nudge Translator

Use whenever a coach gives the avatar an order mid session.

## Method

- Take the order in the coach words, however rough, and restate it as the change they seem to want in one short line.

- Map the order to the question categories and dials it should move, with a signed size for each move.

- Show the coach what moved before the next beat of play, because a nudge the coach cannot see teaches nothing.

- Apply the nudge as temporary for this session, and never write it into the permanent sheet without a debrief ruling.

- Refuse the part of any nudge that touches a non nudgeable question, and offer the closest in bounds version instead.

- Log the order, the mapping and the observed effect in the session log for the debrief.
