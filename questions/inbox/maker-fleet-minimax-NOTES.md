# Fleet mining — MiniMax pass, 2026-10-14

Route: MiniMax API via ~/workspace/skills/minimax/bin/chat.py
(MiniMax-Text-01), one mining prompt for maker-perspective
spectrum questions. Kept verbatim in session records.

What came back: 15 design-axis items in a textbook register
(starting advantage, resource scarcity, level linearity, economy
complexity, replayability...), ignoring the requested output
format. Assessment, plainly: as questions about how games SHOULD
be designed they are flat for this database — most either
duplicate existing coverage from the game side (failure
punishment, tutorial integration, difficulty progression) or
measure a game's genre rather than anything an avatar does.

Salvage: 6 of the axes became real questions after reframing
from "how should a game be" to "what does the avatar detect
and do about it" (fleet-001 to fleet-006, category maker-reading).
Dropped 9 as duplicates or textbook-flat, per the shading test:
a question whose answer changes no behaviour earns no row.

Lesson for fleet mining: the fleet model drafted breadth
cheaply; the discrimination standard still had to be applied
by the orchestrator. Budget future fleet passes as raw
material generation, never as finished questions.
