# The question graph

The database is not a list, it is a graph. Questions gain power from
their neighbours:

- **Clusters** — questions that usually move together (the premise
  cluster: premise-*, show-001, show-030, visual-005; the energy
  cluster: show-003, escalation-*, commentary-*; the failure cluster:
  failure-*, show-038, stakes-001). A creator shaded on one node of a
  cluster gives a prior for the others, and a disagreement inside a
  cluster is a signal to look closer, not noise.
- **Tensions** — question pairs where a high answer on one
  constrains the other (strategic silence show-031 against
  near-constant energy show-003; witnessed-only knowledge role-010
  against audience-level certainty; stake inflation against stake
  deflation inside stakes-001). Tensions are where characters live:
  anyone can max one dial, a personality is how the tension resolves.
- **Dependencies** — questions that only make sense once another is
  answered (all nudge-* questions depend on the coach relationship
  existing; visual-* questions depend on frame tooling that does not
  exist yet, so they sit unshaded by design).

Mining rule that follows: the most valuable new question is usually
found ON an edge — where two creators in a cluster disagree, or
where a tension nobody has named shows up in a transcript. The
stake-direction question (stakes-001) was found exactly there, in the
gap between Neotastic inflating and GrayStillPlays deflating.

## The two tracks (Casey, 2026-10-14)

- **Audio track** — these creators talk through the whole video, so
  the transcript carries the game state, the decisions and the
  commentary craft. Everything sampled so far lives here.
- **Visual track** — how the picture is built: cut pace, zooms,
  captions, scale shots, thumbnail grammar (visual-001 to
  visual-012). Learned separately, on its own schedule, because it
  needs frames, not words. Neither track is a substitute for the
  other, and a full character eventually needs both.
